GitGallery Support

GitGallery backs up your photos and videos to a private GitHub repository you own. It runs on iPhone, Android and the web.

Get help

Report a problem or ask a question on GitHub. Include your device, iOS or Android version and what you were doing.

Open a support request

Common questions

Do I need a GitHub account? Yes, a free one works. To look around first, tap "Try the demo" on the welcome screen.

Where are my photos stored? In a private repository in your own GitHub account. GitGallery creates it the first time you sign in. Large videos are stored as release files in the same repository.

Signing in shows a code. What do I do? Open github.com/login/device, sign in to GitHub, enter the code shown in the app and approve GitGallery.

How do I remove everything? Delete the repository on GitHub and revoke GitGallery under GitHub Settings → Applications. See the privacy policy.

# GitGallery screenshots

## Image sizes and capture details

Full-resolution WebP files retain the original capture dimensions. Photo-heavy screens use quality 90; UI screens use lossless compression where that produces smaller files. README previews are 600 pixels wide at quality 86, displayed at 240 pixels wide. Every embedded image uses a raw GitHub URL.

The original PNG captures were backed up locally outside the repository before conversion. Original capture filenames, dimensions, byte counts, and SHA-256 checksums are retained alongside the current WebP and preview checksums in the [Android manifest](android/capture-manifest.json) and [iOS manifest](ios/capture-manifest.json). Media sources are recorded in [media-sources.json](media-sources.json).

Captures came directly from ADB or `xcrun simctl io screenshot`, using devices and runtimes already installed on the machine. No frames or promotional overlays were added.

The capture builds used the separate identifier `com.gitgallery.screenshots`. The repository, upload status, and cloud index were offline demo data; photos, videos, and albums were installed in each emulator's actual media library. Temporary authentication and data fixtures were removed from the app source after capture, with the original files restored byte-for-byte.
